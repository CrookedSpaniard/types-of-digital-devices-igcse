# Types of digital devices — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 1 Digital devices**: the types of digital device (book pages 5–15).

Each section is explained step by step with interactive simulations, followed by the book's **activities** (where the book has them) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes).

**Part A · Computers, phones and tablets**

1. Types of digital devices — the range from microprocessor to supercomputer, a mainframe serving many users and running a bulk job, the microprocessor inside a washing machine (input → process → output), find the microprocessors at home → Activities → ✓ Check
2. Personal computers — connect peripherals and upgrade a desktop, all-in-one, laptops are portable (unplug test), desktop replacements, the Raspberry Pi Zero and a physical-computing button + LED → ✓ Check
3. Mobile phones and smartphones — inserting a SIM card, the emergency button calling a list of contacts, a talking phone (browser speech), text size and colours, apps, a virtual keyboard and battery life → Activities → ✓ Check
4. Tablets — tablet vs smartphone, a walk to school in and out of Wi-Fi range (Wi-Fi only vs SIM card slot) → ✓ Check
5. Test Part A

**Part B · Cameras, entertainment and smart devices**

6. Cameras and camcorders — frame rates (Figure 1.12), lens, image processor and sensor, pixels and pixelation with Table 1.1 → ✓ Check
7. Home entertainment systems — TV resolutions (Figure 1.14) and viewing distance, sound systems (USB, Bluetooth, Wi-Fi), PVR and set-top box, smart TV streaming, which disc plays in which player → Activities → ✓ Check
8. Games consoles and media players — a mini-game with a controller, motion sensors and a VR avatar, making a game fit on a handheld, media players, flash memory when jogging → Activities → ✓ Check
9. Navigation aids and smart homes — Sat-Nav route recalculation, GPS and the orientation sensor, maps and the internet, home automation app and a smart assistant (Figure 1.21) → ✓ Check
10. Multifunctional devices and convergence — one smartphone, many functions, Figure 1.24 animated, phablets, 360° laptops and tablets with keyboards → Activities → ✓ Check
11. Test Part B · Key terms (searchable)

**Progress that students can share and resume** (same system as *Connectivity* and *Input devices*)

- Everything is saved automatically in the student's browser (`localStorage`, key `td-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`TD1Z.…`) to carry on with another device.
- Nothing is sent to a server. The camera and microphone are never used.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#cameras` or `#check-cameras`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step. All simulations and drawings are original; the people and places are made up, except examples taken from the book.
